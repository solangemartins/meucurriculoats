# **Meu Currículo ATS**

Aplicação web criada com Lovable para gerar currículos profissionais otimizados para sistemas ATS (Applicant Tracking Systems), permitindo criar, editar, analisar e adaptar currículos para vagas específicas.

## **Problema Resolvido**

Muitos candidatos possuem experiência e qualificação, mas seus currículos não são bem interpretados pelos sistemas ATS utilizados em processos seletivos.

O Meu Currículo ATS ajuda a organizar informações profissionais em um formato compatível com esses sistemas e oferece análises de compatibilidade com vagas, destacando pontos fortes, lacunas e oportunidades de melhoria.

### **Funcionalidades**

 ● Criação de currículo profissional
 ● Modelos otimizados para ATS
 ● Visualização em tempo real
 ● Avaliação da qualidade de preenchimento
 ● Análise de compatibilidade com vagas
 ● Identificação de palavras-chave relevantes
 ● Sugestões de melhoria para o currículo
 ● Geração de versão adaptada para a vaga analisada
 ● Exportação em PDF textual
 ● Salvamento de currículos na conta do usuário

**Como Funciona**

**1. Criação do Currículo**
 
O usuário preenche informações como:

 ● Dados pessoais
 ● Objetivo profissional
 ● Experiência profissional
 ● Formação acadêmica
 ● Habilidades
 ● Cursos e certificações
 ● Idiomas
 ● Projetos

**2. Análise ATS**
   
O usuário pode colar uma descrição de vaga.

O sistema compara os requisitos da vaga com o currículo preenchido e gera:

  ● Nota de compatibilidade
  ● Palavras-chave identificadas
  ● Palavras-chave recomendadas
  ● Pontos fortes
  ● Lacunas encontradas
  ● Sugestões de melhoria
 
**3. Currículo Adaptado**
   
Com base na análise, uma versão otimizada do currículo é gerada para melhorar o alinhamento com a vaga.

Importante: o sistema não cria experiências profissionais, certificações, competências ou formações inexistentes no currículo original.

**4. Exportação**
   
O currículo pode ser exportado em PDF textual, mantendo uma estrutura favorável à leitura por sistemas ATS.

**Processo de Desenvolvimento**

Este projeto foi desenvolvido utilizando a abordagem de IA assistida por prompts através da plataforma Lovable.

Após a geração inicial, foram realizados refinamentos sucessivos para:

  ● Melhorar a experiência do usuário
  ● Otimizar o layout ATS
  ● Adicionar exportação em PDF
  ● Aprimorar a análise de compatibilidade
  ● Tornar as recomendações mais transparentes
  ● Reduzir promessas absolutas relacionadas à aprovação em ATS
 
 **Melhorias Realizadas Após a Primeira Versão**
 
Durante o desenvolvimento foram implementados diversos ajustes:

  ● Revisão dos textos para evitar promessas de aprovação garantida
  
  ● Inclusão de mensagens de transparência sobre o uso da IA
  
  ● Estruturação do currículo em formato ATS-friendly
  
  ● Aprimoramento do sistema de análise por vaga
  
  ● Melhoria da visualização do currículo em tempo real
  
  ● Implementação do armazenamento de currículos

**Observação**

O objetivo da aplicação é ajudar candidatos a estruturarem melhor seus currículos e alinhá-los às exigências das vagas analisadas.

Nenhuma análise garante aprovação em processos seletivos, pois cada empresa utiliza critérios próprios de recrutamento e diferentes sistemas ATS.
